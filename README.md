# Project 4: Attendance App (GPS)

## About

The Attendance App is a location-based presence tracking system designed for educational institutions. It leverages GPS technology to automatically mark students as present when they are near their respective campus locations. The app provides real-time visibility of attendance status for both students and instructors, with features to view attendance records and see who else is currently checked in on campus.

### Key Features

**For Students:**
- Automatic presence detection when near campus (app must be open)
- Visual display of current attendance status
- Historical view of all attendance records
- See which other students are currently checked in on campus

**For Instructors:**
- Real-time overview of checked-in students
- Attendance data organized by:
  - Campus location
  - Date
  - Arrival time
- Comprehensive reporting capabilities
